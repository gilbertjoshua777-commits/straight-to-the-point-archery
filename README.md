# Straight to the Point Archery

## Project Overview
A responsive website created for Straight to the Point Archery, an archery instruction business. This project was developed as part of the University of Washington Front-End Web Development course.

A JavaScript powered signup menu was retroactively added to the classes page.

## Features
- Responsive website design
- Home, Classes, Instructors, and Contact pages
- Navigation between website pages
- Image galleries and styling
- Font Awesome integration
- Accessibility features
- Anti-Discrimination Policy page

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 📋 Project Strategy & User Stories
To bridge my Figma mockups with functional code, I focused on solving specific problems for the archery community. While the full project spans multiple demographics, I prioritized the following core user stories during design and development:

*   **User Story 1 (Beginner Experience):** *As a beginner, I want to see what classes are available and understand their costs so I can choose the right starting point and plan my budget.* (Implemented via the **Classes** page layout)
*   **User Story 2 (Community Engagement):** *As a community member, I want to find the location and contact information easily so I know how to get in touch.* (Implemented via the **Contact** page components)
*   **User Story 3 (Post-Course JavaScript Feature):** *As a prospective student, I want a functional and responsive sign-up form with instant validation so I can confidently enroll in a class without processing errors.* (Implemented via custom **Vanilla JS form manipulation**)

---

## 🎨 Connecting Figma to Code (UX to Dev)
Before writing the HTML and CSS, I designed the user interface in Figma to map out exactly how these user stories would live on the screen.
*   **Responsive Execution:** I translated my mobile-first Figma designs into clean code using CSS Flexbox/Grid to seamlessly handle the layouts required by User Story 1 & 2.
*   **Figma-to-JS Handoff:** I designed the physical states of the input fields and error messages for the sign-up form in Figma before executing the logic in JavaScript.
